# Projects

## Active

### kwik.gg

Zero-knowledge encrypted file sharing. Files are encrypted client-side before upload. No accounts, no logs, no server-side access to content.

- **Stack:** Next.js, TypeScript, nginx (custom config for 50GB+ transfers)
- **Domains:** [kwik.gg](https://kwik.gg), [kwik.zip](https://kwik.zip)
- **Status:** Live, actively maintained

### connlog

Connection logging and observability tool. Built for self-hosted infrastructure monitoring.

- **Stack:** TypeScript, Next.js, PostgreSQL
- **Status:** Private, in development

### devdown-ticketsystem

Multi-tenant ticketing system with shared account architecture.

- **Stack:** Next.js, Prisma, PostgreSQL, NextAuth
- **Status:** Production-ready, deployed internally
