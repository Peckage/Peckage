# Stack

What I actually use in production.

## Languages

- **TypeScript** — primary, strict mode, end-to-end type safety
- **Shell** — automation, deployment scripts, server provisioning
- **Python** — scripting, occasional backend work

## Frontend

- **Next.js** — App Router, React 19, Turbopack
- **Tailwind CSS** — utility-first, no custom CSS where avoidable
- **Radix UI** — accessible primitives
- **shadcn/ui patterns** — component structure without the dependency

## Backend

- **Next.js API routes** — co-located with frontend
- **Prisma** — type-safe ORM, PostgreSQL adapter
- **PostgreSQL** — primary database
- **NextAuth v5** — authentication where needed

## Infrastructure

- **nginx** — reverse proxy, rate limiting, security headers, SSL termination
- **Docker** — containerized deployments
- **PM2** — process management for Node apps
- **GitHub Actions** — CI/CD
- **Cloudflare** — DNS, edge caching, DDoS protection

## Security

- Zero-knowledge architecture for sensitive applications
- Client-side encryption before upload
- Strict CSP, HSTS, no referrer leakage
- NIS2-aligned practices for compliance work

## Tools

- **pnpm** — package management
- **Zod** — runtime validation
- **VS Code** — editor of choice
- **Hyprland** — tiling compositor (Linux daily driver)
